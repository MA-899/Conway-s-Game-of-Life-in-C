# Conway's Game of Life in C

## Introduction

This project is a C implementation of the classic [Conway's Game of Life](https://en.wikipedia.org/wiki/Conway%27s_Game_of_Life), created by mathematician John Conway.

## Installation

Clone the repository:

```bash
git clone https://github.com/MA-899/Conway-s-Game-of-Life-in-C.git
cd Conway-s-Game-of-Life-in-C
```

Build and install the program:

```bash
make install
```

To remove generated build files, run:

```bash
make clean
```

## Usage

Start the simulation with:

```bash
conway
```
